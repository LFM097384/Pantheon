# Pantheon 众神殿

> 一个现代化的在线跑团软件，支持实时语音、P2P连接和美观的用户界面。集成了强大的多规则车卡系统。

## 🚀 快速开始

### 环境要求

- Node.js 18+
- npm 或 yarn

### 安装运行

**Windows:**

```bash
双击运行 start.bat
```

**macOS/Linux:**

```bash
chmod +x start.sh
./start.sh
```

**手动运行:**

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
npm run build:dist
```

## 🎲 车卡系统使用指南

### 创建角色

1. 导航到角色管理页面
2. 点击"创建新角色"，进入嵌入式编辑模式
3. 填写角色基本信息（姓名、等级、族裔、职业）
4. 系统自动计算属性调整值、护甲等级、生命值等衍生属性

### 编辑角色属性

1. **基础属性**: 调整六大属性值，系统自动计算调整值
2. **技能系统**: 设置16个标准技能的熟练度，支持自定义技能
3. **专长管理**: 从30+预设专长中选择或自定义专长，自动应用效果
4. **武器配置**: 设置武器熟练度，添加武器并自动计算攻击加值
5. **语言设置**: 多语言支持，可搜索常用语言或自定义添加

### 专长效果系统

- **自动计算**: 专长效果自动应用到相关属性（如健壮专长增加生命值）
- **来源追踪**: 鼠标悬停查看加值来源，如"速度+5 (飞跑专长)"
- **实时更新**: 添加/删除专长时，所有相关数值立即重新计算
- **效果显示**: 专长卡片显示具体效果，如"最大生命值+等级"

### 数据管理

- **本地存储**: 角色数据自动保存到本地
- **导入导出**: 支持角色数据的导入导出功能
- **角色复制**: 快速复制现有角色进行修改

### 规则系统特性

- **完整属性系统**: 六大基础属性，自动计算调整值和衍生属性
- **丰富技能系统**: 16个标准PF2E技能 + 自定义技能支持，彩色熟练度显示
- **专长效果系统**: 30+预设专长，支持自动效果计算和来源追踪
- **武器战斗系统**: 完整的武器熟练度、攻击加值计算，支持近战/远程武器
- **豁免与察觉**: 强韧/反射/意志豁免，察觉检定，职业DC计算
- **语言与速度**: 多语言支持，基于种族的移动速度计算
- **实时计算**: 所有数值变化自动重新计算，专长效果实时生效

## 🔧 技术栈
